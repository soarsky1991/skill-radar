# Media evidence inventory

This directory contains two different evidence classes. Do not treat them as interchangeable.

| Asset | Class | What it supports | What it does not support |
| --- | --- | --- | --- |
| `terminal-fixed-date-replay.png` | `source_evidence` | one local fixed-date render matched the committed report | a live GitHub state, forecast, adoption, demand, or business result |
| `social-preview.png` | `generated_visual` | one radar circle beside one plain signal card; 1280 × 640, 134,247 bytes, SHA-256 `d71c0a8d87eaaf4a3d2e87d245ccad4d4cce8f8a6c542631911565e60770c545` | any command run, interface state, metric, user outcome, or endorsement |

The public terminal image is a privacy-reviewed crop of the full Terminal window. It preserves the command result and boundary statement; it removes unused window area and no content was rewritten. Exact capture metadata, SHA-256 values and claim boundaries are in [`../evidence/media-register.yaml`](../evidence/media-register.yaml).

The Social Preview is image-2 explanatory art from Repo Visual Family R3. It contains no measured data and is not a screenshot.
